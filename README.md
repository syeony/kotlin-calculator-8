# kotlin-calculator-precourse

## 구현할 기능 목록

  - 빈 문자열 입력 시 0 반환
  - 쉼표(,) 또는 콜론(:) 구분자로 숫자 분리 및 합산
  - 커스텀 구분자 파싱 (//구분자\n 형식)
  - 커스텀 구분자로 숫자 분리 및 합산
  - 숫자가 아닌 값 입력 시 IllegalArgumentException 발생
  - 음수 입력 시 IllegalArgumentException 발생
  - Console.readLine()을 사용한 사용자 입력 처리
  - 결과 출력 (형식: 결과 : {합계})
